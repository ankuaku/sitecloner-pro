FAQ

Will the cloned site work offline?

Yes. Everything the page loaded is saved locally. Actions that send data to a server — login, checkout, contact forms — need the original backend, because only the front-end is copied.

What is the difference between Static and Interactive?

Static is a frozen, editable copy of exactly what is on screen: HTML + CSS + images, no JavaScript. It opens with a double-click. Interactive keeps the site's own JavaScript and replays everything the page loaded, so menus, sliders and page switching work. Open it with the included start file or upload it to any hosting.

Does it work with React / Next.js / Vue sites?

Yes. Use the Smart engine — it loads the page in a real browser, waits for it to finish, scrolls to load lazy images and then captures everything, including styled-components and Emotion styles.

Can I clone any website?

Only clone sites you own or have permission to copy. Designs, logos and text are usually protected by copyright and trademarks — use clones for learning, backups or as a starting point for your own original design.

How long are files kept?

ZIP files are removed automatically after a short period.
